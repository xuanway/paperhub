# COGENT: Adaptable Compiler Toolchain for Tagging RISC-V Binaries

**中文标题：** COGENT：面向 RISC-V 二进制标记的可适配编译器工具链

**所属 Session：** [Session 7B](index.md) · [ASPLOS 2026](../index.md)

**作者：** David B Demicco (Binghamton University), Matthew Cole (Binghamton University), Gokturk Yuksek (Binghamton University), RaviTheja Gollapudi (Binghamton University), Aravind Prakash (Binghamton University), Kanad Ghose (Binghamton University), Zerksis D Umrigar (Binghamton University)

**单位：** Binghamton University

**来源：** ASPLOS 2025 · Volume 3 · [论文 DOI](https://doi.org/10.1145/3676642.3736125) · [官方日程](https://www.asplos-conference.org/asplos2026/program/index.html)

## 英文摘要

Tags, or metadata, enrich software with domain-specific information that is consumed by hardware to enforce security and testing policies during runtime. However, given a target architecture, developing custom compilers that encode tags can be tedious and time-consuming. We present COGENT, a highly flexible and feature-rich compiler toolchain for instruction tag generation on the RISC-V architecture. Central to this effort is a LLVM-based compiler that is supplemented with a tag-aware disassembler and a tag integrity checker. COGENT is capable of: (a) generating tags at one or more of varying granularity (per function, per basic block, or per instruction), and (b) associating variable-width tags (1-32 bits) to instructions, and arbitrary-width tags to each function or basic block. Additionally, COGENT is capable of emitting control-flow labels, which are crucial in asserting control-flow integrity (CFI), a runtime property that aids in detecting bugs and exploits that violate control flow. We evaluate the correctness of tags generated by COGENT's compiler and the associated performance penalties, along with how well COGENT preserves IR-level tags at the lower level. We provide three exemplar applications–Control Flow Integrity, Adaptive Tracing, and Hardware-Level Function The tagged code incurs an average cycle count overhead from 5.24% to 0.94% in the worst and best cases, respectively, making it ideal for debugging and testing applications, including fuzzing.

## 中文摘要

标签（tag），即元数据，为软件补充领域特定信息，这些信息由硬件在运行时读取以实施安全和测试策略。然而，针对某一目标架构开发能够编码标签的定制编译器既繁琐又耗时。我们提出 COGENT，一个高度灵活、功能丰富的编译器工具链，用于在 RISC-V 架构上生成指令标签。该工作的核心是一个基于 LLVM 的编译器，并辅以标签感知反汇编器和标签完整性检查器。COGENT 能够：(a) 以一种或多种不同粒度（按函数、按基本块或按指令）生成标签；(b) 将可变宽度标签（1-32 位）关联到指令，并将任意宽度标签关联到每个函数或基本块。此外，COGENT 能够发出控制流标签，这对于断言控制流完整性（CFI）至关重要；CFI 是一种运行时属性，有助于检测违反控制流的缺陷与攻击利用。我们评估了 COGENT 编译器所生成标签的正确性及相关性能代价，以及 COGENT 在更低层次上保留 IR 级标签的效果。我们提供三个示例应用——控制流完整性、自适应追踪和硬件级函数 被标记的代码在最差和最好情况下分别带来平均 5.24% 至 0.94% 的周期数开销，这使其非常适合调试与测试类应用，包括模糊测试。
