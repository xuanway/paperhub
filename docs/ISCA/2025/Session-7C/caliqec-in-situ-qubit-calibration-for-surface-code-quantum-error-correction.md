# CaliQEC: In-situ Qubit Calibration for Surface Code Quantum Error Correction

**中文标题：** CaliQEC: 表面码量子纠错的原位量子比特校准

**所属 Session：** [Session 7C](index.md) · [ISCA 2025](../index.md)

**作者：** Xiang Fang, Keyi Yin, Yuchen Zhu, Jixuan Ruan, Dean Tullsen, Zhiding Liang, Andrew Sornborger, Ang Li, Travis Humble, Yufei Ding, Yunong Shi, Dean Tullsen

**来源：** ISCA 2025 · [论文 DOI](https://doi.org/10.1145/3695053.3731042) · [官方日程](https://www.iscaconf.org/isca2025/program/)

## 英文摘要

Quantum Error Correction (QEC) is essential for fault-tolerant, large-scale quantum computation. However, error drift in qubits undermines QEC performance during long computations, neces- sitating frequent calibration. Conventional calibration methods disrupt quantum states, requiring system downtime and rendering in situ calibration impractical. To address this challenge, we pro- pose QECali, a novel framework that enables in situ calibration for surface codes. Our evaluation demonstrates that QECali introduces modest qubit overhead and negligible increases in execution time, offering the first practical solution for in situ calibration in surface code based quantum computation.

## 中文摘要

量子纠错（QEC）是实现大规模容错量子计算的基础。但在长时间计算过程中，量子比特的错误漂移会劣化量子纠错性能，因此需要频繁校准。传统校准方式会破坏量子态，导致系统停机，难以实现原位校准。针对该难题，本文提出QECali，一套面向表面码的原位校准新框架。评测结果表明，QECali仅带来少量量子比特开销，执行时间几乎没有增加，是首个适用于基于表面码的量子计算、具备实用性的原位校准方案。
