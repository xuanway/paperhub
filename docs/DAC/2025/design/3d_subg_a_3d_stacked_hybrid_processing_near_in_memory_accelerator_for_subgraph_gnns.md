## 研究概要
本文提出3D-SubG三维堆叠近存/存内混合加速器，面向子图图神经网络。采用混合键合堆叠逻辑裸片与DRAM裸片，设计比特级非零收集稀疏优化、负载均衡子图映射、分布式全局池化三大技术。22nm流片对比RTX3090Ti，平均性能提升146.11倍，能效提升1171.80倍。

## 背景和动机
1. 子图GNN表达能力更强，但会生成海量独立不规则子图，顶点数量激增，传统GPU/CPU访存与并行效率极低。
2. 现有GNN加速器仅适配单图标准GNN，无法高效并行处理大量子图，存在严重负载不均、跨块数据搬运开销大的问题。
3. 子图特征矩阵高度稀疏，传统固定数据流存内单元难以挖掘稀疏性，冗余计算多。
4. 二维架构片外带宽受限，子图并行处理带来海量不规则访存，存储墙瓶颈突出。

## 相关工作
1. 传统GNN专用加速器：仅针对原图消息传递优化，不支持子图多级并行，缺少子图负载均衡调度。
2. 二维存内/近存计算架构：裸片间带宽低，无法支撑大规模子图并发的数据吞吐。
3. 通用数字PIM宏单元：数据流固化，不能灵活重组稀疏特征，缺少比特粒度稀疏跳过机制。
4. 集中式全局池化方案：所有子图特征汇总至单块计算，通信量巨大且单块负载过载。

## 本文解决方案
### 1. 3D堆叠混合近存架构
采用混合键合工艺垂直堆叠逻辑裸片与DRAM裸片，划分6×6逻辑-DRAM（L2D）块，裸片间高密度铜柱提供超高带宽；逻辑裸片集成数字存内DPIM与SIMD双引擎，分别处理稠密权重乘、稀疏聚合运算。
### 2. 比特级非零收集稀疏优化DPIM
通道独立DPIM宏，可跨子阵列读取权重；将同通道非零数据聚合至少量计算字，大量全零计算块直接跳过，大幅削减稀疏矩阵运算周期。
### 3. 贪心负载均衡子图映射
按子顶点数量降序排序，依次分配至当前负载最轻L2块，均衡多子图并行时各硬件块计算量，提升整体硬件利用率。
### 4. 分布式全局池化
各L2块先完成本地子图池化，仅传输压缩后的子图表征，将跨块传输规模从子图总数降至硬件块总数，降低通信量并均衡负载。

## 实验分析
1. 实验配置：22nm工艺、200MHz，6×6 L2块架构；测试MUTAG/BZR/ENZYMES/PROTEINS四类子图数据集，基准为RTX3090Ti。
2. 稀疏优化收益：比特级非零收集平均减少1.5~2.5倍计算字，优于元素级稀疏方案。
3. 映射策略：硬件块平均利用率从80%提升至90%，消除严重负载倾斜。
4. 分布式池化：跨块数据传输量最高降低4.32倍，全局池化延迟缩减2.37倍。
5. 整机对比：相较RTX3090Ti，平均性能146.11倍、面积效率934.18倍、能量效率1171.80倍，整机功耗仅4.17W。

## 研究启发
1. 子图GNN存在两级并行（子图并行、图内消息传递并行），3D堆叠近存架构是释放多层并行的最优硬件载体。
2. GNN稀疏优化不能停留在元素粒度，比特级数据重组可进一步削减冗余计算，适配数字存内单元硬件特性。
3. 子图尺寸差异极大，贪心均衡映射是低成本、高效的调度方案，无需复杂在线重划分。
4. 池化阶段易被忽视，但集中式聚合会带来巨大通信瓶颈，分层分布式聚合可显著降低片上网络开销。
5. 混合DPIM+SIMD异构引擎可匹配GNN两类计算特征：稠密权重矩阵用PIM、稀疏邻接聚合用SIMD，单一计算单元难以兼顾。
