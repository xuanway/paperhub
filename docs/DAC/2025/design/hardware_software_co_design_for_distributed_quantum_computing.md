## 研究概要
本文面向分布式量子计算(DQC)提出软硬件协同架构，划分通信/缓存/数据三类量子比特，采用异步纠缠生成与远程门自适应调度。预存纠缠缓冲平滑资源供给，实时匹配EPR对供需。在TLIM、QAOA、QFT等基准验证，相较无缓冲基线电路深度大幅缩减，输出保真度提升2倍左右。

## 背景和动机
1. 单片量子芯片受串扰、布线约束难以扩规模，分布式多QPU是规模化核心路线，但远程纠缠生成概率低、周期远长于本地门。
2. 远程CNOT等操作依赖Bell对(EPR)，纠缠生成与电路执行同步执行时，量子比特长时间闲置退相干，保真度暴跌、电路深度激增。
3. 同步批量生成纠缠会出现资源脉冲式堆积，缓存溢出或长时间存储加剧退相干，现有方案缺少平滑供给机制。
4. 传统DQC调度仅离线划分电路，无法根据实时缓存内可用EPR对动态调整远程门执行时机，资源匹配效率低。

## 相关工作
1. AutoComm/QuComm：分布式量子编译工具，仅离线规划通信，未解决纠缠生成的概率与时序波动问题，缓冲设计单一。
2. 量子图划分类方法：仅优化比特跨节点分配，不针对纠缠资源供给做硬件缓存与时序调度协同。
3. 强化学习DQC编译：侧重电路分层映射，未从硬件比特分层、异步生成底层优化纠缠供给。
4. 量子互连硬件研究：聚焦光子传输与BSM硬件，缺少配套软件自适应调度配合。

## 本文解决方案
### 1. 三类分层量子比特硬件架构
区分通信比特（持续生成远程纠缠）、缓存比特（SWAP暂存Bell对）、数据比特（执行计算）；生成成功后交换释放通信比特，支持预初始化纠缠储备。
### 2. 异步远程纠缠生成机制
通信比特分组错峰发起纠缠生成，打散脉冲式Bell对产出，均衡各时段资源供给，减少缓存长时间存储带来的退相干损耗。
### 3. 远程门自适应实时调度
电路预分段并编译ASAP/ALAP两套等效子电路；实时读取缓存EPR数量，充足则提前执行远程门，不足则延后，动态匹配资源供给。
### 4. 软硬件协同仿真建模
搭建含光子损耗、BSM概率、比特退相干的DQC仿真框架，量化缓存、异步、调度三模块对深度与保真度增益。

## 实验分析
1. 测试基准：TLIM、4/8度QAOA、QFT，覆盖低/中/高比例远程门场景，配置32/64比特双节点DQC系统。
2. 电路深度：无缓冲基线深度极高；同步缓冲降61.7%，异步再降7%，自适应调度叠加预初始化后深度最优。
3. 保真度：异步+自适应方案相较原始基线平均提升2倍，同步缓冲仅提升1.32倍；预初始化缩短时延但会小幅损耗保真。
4. 扩展性：提升通信/缓存比特数量持续优化性能，20组比特可逼近单片理想电路深度；64比特大规模基准增益稳定。
5. 消融：缓存是核心增益来源，异步生成平滑供给，自适应调度进一步缩小等待时延，三者缺一增益大幅衰减。

## 研究启发
1. DQC性能瓶颈不在光子互连硬件，而在纠缠资源供给与电路执行时序不匹配，分层缓存比特是低成本优化手段。
2. 同步批量生成纠缠会造成资源脉冲浪费，错峰异步生成可均衡负载，显著降低缓存内纠缠的闲置退相干。
3. 仅离线编译无法适配概率性Bell对生成，预存多版本子电路+实时切换是轻量自适应调度可行方案。
4. 通信、缓存、计算功能比特物理隔离，实现纠缠生成与量子计算并行，充分利用硬件时间资源。
5. 规模化DQC软硬件必须协同设计，仅优化编译或仅改进光子硬件均无法同时大幅降低时延与提升保真。
