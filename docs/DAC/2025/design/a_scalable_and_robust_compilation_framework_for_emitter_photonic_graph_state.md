## 研究概要
本文面向发射光子确定性图态编译难题，提出可扩展鲁棒编译框架。采用分治思想结合有限局部补全MIP图划分，子图独立编译后分时调度实现发射源复用，兼顾CNOT数量、电路时长、光子损耗多目标优化。相较基线，CNOT最高缩减52%、电路时长缩短56%，光子损耗抑制最高1.9倍。

## 背景和动机
1. 确定性发射光子图态相比全光子概率方案扩展性更强，但现有编译仅单一指标优化，忽略发射源、光子损耗等硬件约束，实用度低。
2. 全局最优图态求解、最优局部补全均为#P完全问题，暴力搜索指数级开销，无法扩展到大规模多光子图。
3. 现有编译只最小CNOT门数，未考虑发射CNOT耗时远高于光子发射，电路持续时间过长加剧光子累积损耗。
4. 编译后子电路发射源利用率低，大量空闲发射单元拉长电路周期，进一步提升光子丢失概率。

## 相关工作
1. 全光子概率图态编译器：依赖融合门，随机度高、资源指数增长，不适用于确定性发射硬件。
2. 发射源类专用编译GraphiQ：仅全局暴力搜索，规模超过10量子比特后运行时间超千秒，仅优化CNOT数量。
3. 局部补全优化研究：证明可降低图边数，但无分治适配，全局搜索无法用于大图。
4. 损耗感知单类图编译：仅针对中继图，不支持晶格、随机、树等通用量子图结构，通用性差。

## 本文解决方案
### 1. 带局部补全的MIP图分治划分
限定局部补全最大步数降低求解复杂度，以跨子图边数最小为目标划分大图为尺寸可控子图，大幅削减全局搜索空间。
### 2. 多目标子图独立编译
基于时序逆约简模型，采用顶点度启发式深度搜索，优先减少发射CNOT；以平均光子留存时长为第二优化目标，延迟光子发射降低损耗；支持可变发射源上限适配硬件。
### 3. 分时复用电路调度
子电路按光子数/时长权重排序，采用尽可能延后调度策略；时隙内复用闲置发射源，充分利用硬件容量压缩总电路时长。
### 4. 硬件感知综合代价函数
结合量子点门真实时延建模，统一量化CNOT数量、电路总周期、光子累积损耗三维优化目标，输出适配固态发射硬件的量子电路。

## 实验分析
1. 测试基准：晶格、树、Waxman随机三类主流量子图，硬件采用硅量子点发射模型，对比GraphiQ基线。
2. CNOT缩减：晶格/树/随机图平均降幅25%/28%/37%，最高分别达40%、39%、52%。
3. 电路时长：发射源上限1.5/2倍最小需求下，最高缩短50%、56%，发射资源越多并行增益越明显。
4. 光子损耗：三类图损耗平均抑制1.3/1.4/1.9倍，局部补全可大幅减少跨子图纠缠边，降低电路周期。
5. 扩展性：单张子图编译耗时低于100秒，大规模图分块后整体编译时间可控，突破基线规模限制。

## 研究启发
1. #P完全类量子图优化问题，分治+有限局部变换是兼顾精度与可扩展性的可行折中路线。
2. 量子编译不能仅门计数优化，必须耦合硬件门时延、光子时序损耗等底层物理约束。
3. 发射源复用与时序调度是降低图态生成时长、抑制光子丢失的核心手段，并行潜力巨大。
4. 局部补全与图划分联合建模，能从源头减少昂贵发射CNOT纠缠边，双重降低硬件开销。
5. 通用量子编译器需模块化子图编译+全局调度双层架构，适配MBQC、QRAM、量子网络多类图态场景。
