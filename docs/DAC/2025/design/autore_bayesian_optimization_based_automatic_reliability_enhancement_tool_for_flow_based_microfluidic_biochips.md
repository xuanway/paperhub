## 研究概要
本文提出AutoRE，首款基于贝叶斯优化的流控微流控芯片版图自动可靠性提升工具。在保持拓扑不变前提下分段微调版图，搭配堵塞、泄漏双失效量化模型，采用随机森林代理与logEI采集函数寻优。全部测试用例平均可靠性提升约40%，相比随机搜索寻优效率大幅提升。

## 背景和动机
1. 流控微流控芯片制造易出现通道堵塞、泄漏缺陷，集成度提升后缺陷概率激增，芯片良率低下。
2. 现有容错方案仅新增备份通路，缺少可量化的版图可靠性评估与自动优化手段，无法定量提升良率。
3. 版图微调可行域内变体数量庞大，暴力遍历开销极高，传统搜索策略收敛速度慢、优化效果差。
4. 已有堵塞、泄漏可靠性量化模型，但缺乏配套自动化版图优化工具落地使用。

## 相关工作
1. 容错版图设计：构建共享阀、备份通道、扩展布线层，仅靠冗余硬件容错，无量化评估与自动调优流程。
2. 微流控可靠性量化模型：建立堵塞、泄漏失效概率计算方法，但未结合版图优化工具。
3. 传统贝叶斯优化：多采用高斯过程代理，高维空间易梯度消失，不适用于版图微调场景。
4. 版图随机微调方法：无引导盲目搜索，大量无效采样，优化收敛速度慢、最终可靠性提升有限。

## 本文解决方案
### 1. 可行域自动生成算法
将版图拆分为横竖通道段，识别通道上下边界与邻接约束，构建区间约束；微调仅单轴向移动通道，纵向通道自适应伸缩，全程保留电路拓扑与生化功能。
### 2. 加权可靠性目标函数
融合堵塞失效概率$P_{blockage}$、泄漏失效概率$P_{leakage}$，权重w可自定义，适配不同制造缺陷场景的优化偏好。
### 3. 改进贝叶斯优化框架
选用随机森林RF作为代理模型适配高度非线性代价；采用logEI采集函数解决高维梯度消失问题，搭配局部启发搜索加速采样。
### 4. 双轮交替寻优流程
x、y轴向分轮交替优化，每轮限制采样次数，迭代至可靠性提升低于阈值后输出最终优化版图。

## 实验分析
1. 测试基准：3个人工合成、3款工业真实微流控版图，设置w=0/0.5/1三组权重对比。
2. 优化效果：抗堵塞可靠性平均提升42.53%，抗泄漏平均提升37.59%，综合平均提升约40%；权重可调可定向优化单一缺陷类型。
3. 寻优效率：贝叶斯引导搜索远优于随机遍历，同等采样次数下代价下降幅度更大，所有案例运行时长可控。
4. 版图适配：不同通道密度芯片均可完成微调，高密度版图优化增益更显著；可按需牺牲一类可靠性换取另一类大幅提升。

## 研究启发
1. 微流控可靠性优化无需新增冗余通道，仅微调通道间距与位置即可显著降低堵塞、泄漏概率。
2. 拓扑保持式分段微调可在不改动生化实验流程前提下完成良率提升，适配现有芯片设计流程。
3. 传统高斯过程不适合版图高维非线性优化，随机森林代理搭配log采集函数是更优贝叶斯组合。
4. 双缺陷加权目标函数可适配不同工艺缺陷分布，工具具备灵活工程可调性。
5. 分轴向交替寻优降低优化维度，大幅缩减搜索空间，平衡优化质量与计算耗时。
