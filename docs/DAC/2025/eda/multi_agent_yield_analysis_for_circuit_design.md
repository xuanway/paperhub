## 研究概要
本文提出基于大模型多智能体良率分析框架YieldAgent，构建三层分层智能体架构，结合RAG领域知识库与TPE超参自适应优化，可按电路、工艺、精度动态组合采样算法。40/12nm 6T-SRAM测试，同等误差下仿真量最高缩减2.9倍，跨拓扑、工艺泛化能力优于传统MC与各类重要采样方法。

## 背景和动机
1. 先进工艺晶体管参数维度激增，标准蒙特卡洛(MC)稀有故障仿真开销巨大，工业迭代成本过高。
2. 单一重要采样、代理模型泛化差，跨工艺、电路拓扑精度剧烈下滑，固定策略无法自适应不同失效分布。
3. 现有AI良率工具缺少领域知识沉淀，超参手动调参耗时，难以匹配动态精度与算力预算需求。
4. LLM在EDA各类任务已落地，但尚未用于良率分析的算法动态调度、多方法融合。
5. 缺少统一框架自动完成方法选型、超参调优、收敛判定、仿真调度全链路自动化。

## 相关工作
1. 传统蒙特卡洛MC：精度稳定但稀有事件样本量爆炸，算力消耗难以承受。
2. 重要采样类(MNIS/AOSM/ACS/HSCS)：单策略适配固定失效场景，跨工艺性能断崖式下跌，无动态组合机制。
3. 代理/贝叶斯良率模型(PCE/GP深度核)：依赖大量训练样本，高维电路拟合不稳定。
4. LLM EDA应用：集中于HD生成、RTL调试，未解决良率仿真调度与算法自适应优化。
5. 单流水线良率工具：流程固化，无法根据算力、精度需求动态切换、融合多种采样方案。

## 本文解决方案
### 1 三层分层多智能体协同架构
战略层智能体解析需求确定精度/算力目标；协调层联动知识库完成任务分发；执行层包含代码、仿真、分析、优化四类专用智能体完成仿真与调参。
### 2 RAG行业良率知识库
沉淀MNIS、ACS等主流采样方法跨工艺性能数据，LLM通过上下文推理完成拓扑感知的算法组合推荐。
### 3 TPE树状帕森超参动态优化
以期望提升为目标实时更新采样超参，解决固定超参跨工艺失效分布适配差的痛点。
### 4 滑动窗口收敛判定机制
用窗口相对变异系数RV判定仿真收敛，替代传统单一FoM指标，多算法混合场景判定更稳定。
### 5 闭环自适应仿真流水线
智能体循环执行方法选型→代码生成→批量仿真→结果收敛评估→超参重调/算法替换，自动平衡精度与仿真开销。

## 实验分析
1. 测试对象：40nm、12nm 6T-SRAM，工艺变量包含Vth、tox、迁移率，基准为十万次MC真值。
2. 算力预算测试：低/中/高三档仿真量下，YieldAgent相对误差分别仅4.1%/2.96%/1.8%，全面优于单采样方法。
3. 精度约束测试：收敛阈值0.1/0.05/0.01时，仿真次数相较主流方法缩减最高2.9倍。
4. 跨工艺泛化：40nm优选MNIS+ACS，12nm采用AOS+ACS组合，可适配不同失效区域特征。
5. 消融验证：RAG知识库、TPE超参调优、多智能体动态调度均为核心增益模块，移除后误差显著上升。

## 研究启发
1. 单一良率采样算法存在场景局限性，基于LLM多智能体动态融合多策略是高效优化路线。
2. 工艺与电路拓扑直接决定失效分布，必须依托历史性能库做数据驱动的自适应方法选择。
3. 静态超参无法适配不同工艺，贝叶斯TPE在线调参可大幅降低人工调参成本并提升精度。
4. 滑动窗口相对变异比传统收敛指标更适合多算法混合仿真的良率判定场景。
5. 将LLM推理用于EDA数值仿真调度，可实现从需求输入到良率报告全流程自动化，适配先进节点大规模电路迭代。
