## 研究概要
本文面向多核共享存储验证，提出一种基于执行见证的强化学习环境状态表征方案。复用读-写依赖关系定义多核执行见证，设计唯一数值签名编码观测，采用定长动作-观测历史近似马尔可夫状态。基于16/32核MOESI架构测试，相较MTG、RLG等主流方法，收敛速度更快、故障检出耗时大幅缩短。

## 背景和动机
1. 多核并发访存存在非确定执行路径，单一覆盖率指标观测信息不足，强化学习智能体无法精准感知仿真环境完整状态。
2. 现有RL导向测试生成仅以累计覆盖率作为状态输入，丢失多线程访存执行细节，泛化能力差，跨一致性协议适配弱。
3. 传统进化类测试生成（MTG）仅依赖种群局部收益，缺乏长远优化决策，复杂故障检出效率低下。
4. 缺少与存储一致性模型解耦的通用观测提取方式，现有轨迹表征绑定特定架构，复用性低。
5. 无无损、唯一的多核执行编码方法，不同执行实例易映射为相同状态，导致智能体学习混淆。

## 相关工作
1. 进化导向测试生成MTG：基于遗传算法生成并发程序，仅关注当前种群收益，缺少长期规划，大规模多核故障检出慢。
2. RLG强化学习测试生成：仅使用覆盖率作为状态特征，不记录执行轨迹，环境感知能力有限。
3. 贝叶斯测试生成：基于统计推断调整随机约束，无法捕捉细粒度访存依赖行为。
4. 石蕊测试生成：基于读-写关系构造激励，但无面向RL的统一状态编码机制。
5. 通用DQN框架：多基于原始图像观测，无适配多核存储仿真的专用观测提取逻辑。

## 本文解决方案
### 1 多核执行见证观测提取
基于reads-from读写依赖定义单核心见证、全局多核见证，记录各加载操作读取的存储唯一数值，完整捕获并发执行行为，与一致性协议解耦。
### 2 无歧义签名编码机制
约束存储写入唯一自然数，对每核见证数值求和生成签名向量；数学证明该编码为单射，不同执行实例对应唯一观测向量。
### 3 定长历史状态近似方法
采用固定窗口h存储连续动作-观测序列，通过滑动更新构造马尔可夫近似状态，解决部分可观测MDP问题。
### 4 DQG强化测试生成流水线
以覆盖率增量作为奖励函数，智能体基于见证签名状态生成并发测试；单次程序多次仿真采集多执行实例丰富观测。
### 5 通用验证适配架构
兼容结构/功能两类覆盖指标，支持16/32核MOESI缓存一致性，基于gem5仿真平台完成整套激励生成与评估。

## 实验分析
1. 测试平台：gem5仿真器，2级MOESI协议16/32核架构，对比RAG随机、RLG、MTG三类基准。
2. 覆盖收敛：所提DQG*方案在24小时仿真内，所有任务覆盖上升速度显著优于RLG、DQG+（仅覆盖率观测）。
3. 故障检出：针对F2/F3典型一致性故障，DQG*检出中位数远低于MTG；32核场景MTG甚至无法发现F2故障。
4. 消融对比：仅用覆盖率作为观测的DQG+性能明显弱于本文见证签名表征，验证细粒度访存观测价值。
5. 扩展性：架构、覆盖指标切换后性能稳定，方案具备跨多核验证任务通用性。

## 研究启发
1. 仅依靠覆盖率不足以表征多核仿真完整环境，必须提取底层访存依赖行为作为细粒度观测。
2. 基于读写依赖的见证编码可实现架构无关观测提取，大幅提升RL测试生成跨场景泛化能力。
3. 唯一数值签名是轻量化、无损的多核执行表征手段，相比原始海量仿真轨迹更适合神经网络输入。
4. 定长动作-观测历史可有效缓解多核验证POMD部分可观测难题，提升智能体决策质量。
5. 强化学习具备长远优化优势，相比局部最优的进化测试生成，复杂一致性故障检出效率更高。
