## 研究概要
本文提出EDGE框架，借助数据库加速多输出布尔分解用于GIG逻辑综合。将分解转化关系代数查询，设计串行/并行分解配套贪心、链式等策略，分层拆解真值表至小规模子函数。IWLS基准测试，分解速度最高提升21倍，优化后AIG节点总数相较主流fx方法降低15%以上。

## 背景和动机
1. 传统SOP综合仅简单因式分解，难以挖掘多输出间逻辑共享，生成GIG节点规模偏大，时序面积优化上限低。
2. 现有布尔分解基于立方体集合运算，计算复杂、运行极慢，16输入真值表难以在时限内完成求解。
3. BDD类DSD分解仅支持单输出，忽略多输出共享逻辑，窗口尺寸受限，综合收益有限。
4. 分解解空间随输入数指数膨胀，缺乏分层筛选、多策略适配机制，无法适配不同特征布尔函数。
5. 真值表存储与冲突对遍历开销巨大，缺少数据库查询、多线程等工程加速手段。

## 相关工作
1. SOP因式分解工具（ABC fx/fxch）：粗粒度优化，难以挖掘深层多输出共享逻辑，GIG冗余节点多。
2. BDD-DSD布尔分解：仅限单输出，窗口规模受限，无法处理多输出电路。
3. 立方体式布尔分解：依赖复杂集合运算，冲突对遍历计算量爆炸，大规模电路不可用。
4. LUT映射类分解算法：面向FPGA映射，不聚焦GIG底层节点最小化。
5. 传统真值表运算：无数据库索引优化，笛卡尔积遍历耗时极高。

## 本文解决方案
### 1 DBMS驱动串行分解加速
将冲突对求解改写为优化关系代数查询，用排序归并连接、对称剪枝降低计算量；基于图着色构造子函数，分准备/提交两步完成串行分解，DuckDB多线程加速。
### 2 高效界自由集搜索
限定输入支持集合遍历范围，按子函数质量筛选保留Top候选，可选自由集扩展策略提升逻辑复用。
### 3 双启发式并行分解
基于Jaccard距离分层聚类、唯一模式计数两种输出拆分算法，串行无收益时自动启用并行分解。
### 4 多场景自适应分解策略
提供贪心、大真值表、链式三套策略，分别适配通用、超大输入、嵌套链式布尔函数，设置6输入终止阈值。
### 5 分层决策树综合流水线
真值表单元池迭代分解，生成多解树择优输出；子函数达阈值后调用ABC完成GIG生成，分层控制电路结构。

## 实验分析
1. 实验环境：AMD EPYC服务器，DuckDB+NetworkX实现，IWLS2023基准，对比ABC fx/fxch原生分解。
2. 分解效率：同规模真值表分解速度提升10~21倍，16输入场景冲突对计算耗时下降94%~95%。
3. 电路质量：全部基准优化后AIG总节点相较fx降低15%，单组电路最高缩减18%。
4. 规模适配：16输入超大真值表可稳定求解，大真值专用策略大幅缩短搜索时长。
5. 消融验证：数据库查询优化、多策略选择、并行聚类三者缺一不可，移除后节点数与耗时同步恶化。

## 研究启发
1. 布尔分解NP难问题可借助成熟数据库查询引擎做底层加速，替代原生集合暴力遍历。
2. 多输出电路必须搭配并行分解，仅串行分解无法挖掘输出间共享逻辑。
3. 分层分解+小规模子函数阈值截断，能平衡分解开销与最终GIG优化收益。
4. 单一分解策略难以适配全类型电路，按函数嵌套、输入规模设计多套启发策略是有效方案。
5. 真值表相比SOP更易做数据库向量化运算，是大规模布尔分解更优底层表达形式。
