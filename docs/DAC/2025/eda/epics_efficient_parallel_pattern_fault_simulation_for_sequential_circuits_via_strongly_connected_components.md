## 研究概要
本文提出EPICS并行模式故障仿真框架，针对时序电路SCC强连通分量瓶颈，融合小回路编译仿真、入度分层展开、惰性事件传播三类优化。工业RISC-V与ITC基准测试，相比商用Z01X平均提速5.94倍，事件量大幅削减且故障覆盖率完全一致。

## 背景和动机
1. 汽车芯片ISO26262标准要求高诊断覆盖率，大规模时序门级故障仿真周期长达数周，成为芯片验证核心瓶颈。
2. PARIS、VISION等并行模式仿真在组合电路效果优异，但时序电路反馈环路、SCC带来时序依赖，并行效率严重受限。
3. 现有并行仿真依赖多周期状态预测，预测偏差会触发全环路重复事件，产生大量冗余计算。
4. 纯事件驱动仿真频繁调度环路信号，纯编译仿真存储开销爆炸，二者单独使用均存在短板。
5. 缺少面向复杂SCC的专用遍历策略，未区分简单/复杂环路做差异化处理，全局仿真冗余事件过多。

## 相关工作
1. PARIS并行模式仿真：利用位宽并行多输入向量，未针对时序SCC做优化，反馈环路加速效果差。
2. PROOFS/HOPE并行故障仿真：侧重多故障同步传播，无法解决时序循环带来的串行依赖问题。
3. VISION学术仿真器：基础并行架构，无回路编译与惰性传播机制，工业大电路速度不足。
4. 商用Z01X：工业成熟工具，但无SCC分层优化，百万级处理器仿真耗时极高。
5. 传统编译/事件仿真：单一架构，前者时序存储爆炸，后者环路事件调度开销巨大。

## 本文解决方案
### 1 电路SCC拆分与简单回路编译仿真
Tarjan算法拆分强连通分量；仅1~2触发器小型环路编译为复合指令块，批量并行更新多周期状态，省去频繁事件调度；故障直接嵌入编译指令，无额外开销。
### 2 基于入度的SCC分层展开算法
计算节点自入度、前驱总入度综合指标，优先选取依赖最低节点作为环路入口；切断入口输入分层拓扑拆解循环，降低状态预测偏差引发的冗余传播。
### 3 惰性事件传播调度机制
搭建惰性事件记录表，非当前周期预测状态延迟传播；仅当前周期真实信号变更时才触发下游事件，抑制预测错误带来的全环路重复计算。
### 4 混合仿真协同架构
简单环路采用编译仿真，大型复杂SCC使用分层+惰性事件驱动，结合位并行模式仿真，兼顾速度与内存开销。
### 5 完整故障仿真流水线
网表SCC划分→回路分类编译→分层事件遍历→并行多模式传播→故障覆盖率统计，兼容 stuck-at 故障模型。

## 实验分析
1. 实验环境：Xeon铂金服务器，对比商用Z01X、复现VISION+；测试ITC99、开源RISC-V、三款工业处理器电路。
2. 运行速度：相对Z01X平均提速5.94倍，最大工业电路Comm3从22小时降至6小时；相对VISION+提速4.23倍。
3. 事件规模：消融实验显示全套优化后仿真事件仅为原始基线的21.6%，简单回路编译与分层策略均有独立加速收益。
4. 精度保障：全部测试电路故障覆盖率与商用工具完全等同，无精度损失。
5. 可扩展性：千万门级RISC-V openC910仍保持稳定加速，适配大规模工业安全芯片。

## 研究启发
1. 时序故障仿真瓶颈核心是反馈SCC，需区分简单/复杂环路采用编译、事件混合架构，不能单一方案适配所有电路。
2. 环路入口节点依赖度直接决定预测冗余，入度分层拓扑拆解可大幅降低无效事件传播。
3. 惰性延迟传播机制能从根源规避预测偏差引发的环路重复仿真，是时序并行仿真关键优化点。
4. 并行模式仿真与时序拓扑分析结合，可在不降低故障覆盖率前提下大幅压缩验证周期。
5. 面向车规等安全芯片的EDA仿真工具，必须针对性优化百万门级时序循环结构才能落地工程使用。
