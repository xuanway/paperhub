## 研究概要
本文提出PatternPaint少样本扩散修复版图生成框架，仅需20份合规版图微调预训练图像大模型。将版图生成拆解多轮修复流程，搭配模板降噪、PCA样本筛选与双掩码迭代机制，无需数值合法化求解。3nm Intel 18A工艺测试，合规率较原生预训练模型提升1.87倍，是唯一适配复杂2D金属规则的生成方案。

## 背景和动机
1. 先进工艺开发早期设计规则频繁迭代，合规版图样本稀缺，传统GAN/扩散生成方法依赖海量训练数据，落地难度极大。
2. 规则启发式生成工具需人工编码数百条约束，开发周期长，工艺迁移成本高，难以适配多变DR。
3. 现有ML版图生成将拓扑与合法化拆分，依赖非线性求解器，随版图规模、离散约束激增，求解耗时指数级上涨。
4. 学术方案仅在简化设计规则下验证，无法适配工业3nm金属层复杂间距、宽度约束场景。
5. 生成版图边缘噪声严重，大量输出违反线宽、线距规则，合规率低，无法直接用于OPC、热点检测等DFM任务。

## 相关工作
1. 规则启发式版图生成：人工编码DR约束，耦合单一工艺，迭代调整成本极高，模式多样性不足。
2. GAN/Transformer/TCAE生成模型：需要数千份标注版图，新工艺无充足数据时训练失效。
3. 传统扩散版图生成：无专用版图降噪机制，生成图形噪声多，依赖外部求解器合法化。
4. 拓扑+求解两步生成方案：离散约束下转化为混合整数问题，运行效率极低，工业场景不可用。
5. 通用图像修复扩散模型：未针对金属轨道、线距等版图几何约束定制，输出大量违规图形。

## 本文解决方案
### 1 少样本扩散修复基础架构
复用通用图像预训练模型，仅用20份DR合规版图微调；以修复任务替代全局生成，利用局部版图上下文天然嵌入设计规则信息。
### 2 模板导向专用降噪算法
提取生成图与模板扫描线聚类匹配，阈值过滤无效边缘噪声，重构拓扑矩阵，大幅提升版图规则合规性，摒弃求解器后处理。
### 3 PCA代表性样本筛选
对版图降维，最远点贪心选取高多样性样本，兼顾密度、形状约束，迭代生成时避免样本冗余。
### 4 双掩码迭代生成机制
通用掩码、垂直轨道专用掩码两套模板，逐局部区域迭代修复，保留已合规版图结构，持续扩充模式库。
### 5 完整迭代生成流水线
初始样本→PCA选代表→掩码局部修复→模板降噪→更新版图库，循环至达到目标样本多样性上限。

## 实验分析
1. 实验设置：Intel 18A亚3nm工艺复杂金属设计规则，对比传统扩散、GAN、规则生成基线。
2. 少样本效果：仅20份样本微调后版图合规率为原生预训练模型1.87倍。
3. 工业适配性：现有生成方案均无法满足完整2D金属DR，PatternPaint可稳定输出全部合规版图。
4. 多样性指标：PCA筛选+多掩码迭代组合大幅提升模式熵，生成样本覆盖各类金属线结构。
5. 消融验证：模板降噪是合规率核心增益模块，移除后违规版图数量显著上升。

## 研究启发
1. 新工艺版图数据稀缺场景，无需从零训练生成模型，基于图像大模型少样本微调是高效工程路线。
2. 把全局版图生成转化局部修复任务，可天然复用邻域几何约束，省去昂贵合法化求解步骤。
3. 针对版图扫描线、金属轨道定制降噪策略，比通用图像降噪更适配DFM设计规则约束。
4. PCA聚类+分区掩码迭代能在有限样本预算下最大化模式多样性，支撑OPC、热点检测下游任务。
5. 工业版图生成不能仅关注图形外观，必须内置线宽/线距等DR感知模块，否则生成结果无工程使用价值。
