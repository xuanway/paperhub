## 研究概要
本文提出嵌套区域分解并行电源网格求解器Nested DDM，设计并行舒尔补计算与中间舒尔补分层机制，缓解传统DDM全局稠密矩阵规模爆炸、并行效率瓶颈。在IBMPG/THUPG基准测试，全局求解提速1.70倍，整体求解相较传统DDM加速1.30倍，32线程下较CHOLMOD串行求解器提速8.44倍。

## 背景和动机
1. 先进工艺PDN规模达数十亿节点，电源分析需求解大规模SPD稀疏线性方程组，单机直接分解内存开销巨大。
2. 传统单层DDM随划分块增多，全局舒尔补稠密矩阵急剧膨胀，顶层串行求解成为性能天花板，线程越多收益越受限。
3. 单层DDM仅一层子域划分，本地舒尔补与顶层全局补计算无法分层并行，多线程资源利用率低。
4. 现有并行求解器CKTSO、CHOLMOD未分层拆解全局稠密问题，大规模电网并行扩展性差。
5. 缺少分层嵌套分解架构，无法将顶层计算压力分摊至中间并行层，难以充分利用多核算力。

## 相关工作
1. 直接分解求解器CHOLMOD：串行Cholesky分解，超大规模PDN内存与耗时极高，多线程增益微弱。
2. CKTS并行LU求解：单层分块，未分层消解全局稠密舒尔补，顶层串行开销大。
3. 传统单层DDM：仅一次图划分，子域增多后全局矩阵膨胀，并行扩展性差。
4. 代数多重网格、谱稀疏迭代法：收敛不稳定，对复杂电源网格适配弱。
5. 图划分工具METIS：仅提供分图基础能力，无配套分层舒尔补并行计算流程。

## 本文解决方案
### 1 并行舒尔补生成算法
按端口权重均衡分块，并行消除各子域内部节点，批量合并等效电导；支持噪声预测关键端口快速等效化简，适配各类PDN场景。
### 2 双层嵌套区域分解框架
外层划分大子域，每个外层域内部再细分内层子域，形成“内层-中间-全局”三级分层结构。
### 3 中间舒尔补分层化简
每层内层并行消元生成中间舒尔补，将大量计算分摊至多线程，压缩顶层全局矩阵规模，大幅降低顶层串行计算量。
### 4 分层并行回代求解流程
先并行求解所有内层，再并行求解各外层中间层，最后仅小规模全局矩阵串行求解，多层并行最大化线程利用率。
### 5 统一矩阵重排优化
每层分解前做矩阵重排减少填充元，内外层消元复用同一并行分解逻辑，降低代码实现开销。

## 实验分析
1. 实验环境：Xeon双路服务器，128GB内存，IBMPG、THUPG电源基准，对比CHOLMOD、CKTSO、传统DDM。
2. 分层收益：中间舒尔补将顶层计算平均提速1.70倍，整体求解速度较单层DDM提升1.30倍。
3. 多线程扩展性：线程数提升时Nested DDM加速持续上涨，传统DDM很快性能饱和；32线程相对CHOLMOD提速8.44倍。
4. 并行舒尔补消融：两种网格下32线程并行化简分别提速6.73倍、11.6倍，接口节点越少并行效率越高。
5. 分层耗时拆解：内层并行占绝大多数计算时间，顶层串行开销被显著压缩，大规模电路优势更明显。

## 研究启发
1. 单层DDM天然存在扩展性缺陷，嵌套分层分解可拆分全局稠密舒尔补，释放多核并行潜力。
2. 将顶层串行压力下沉至中间并行层是突破并行天花板的核心思路，无需改动线性方程组基础求解逻辑。
3. 舒尔补计算全程可并行化，提前均衡图分块能进一步提升多线程负载均衡度。
4. 电源网格天然分层拓扑适配嵌套DDM架构，该分层范式可拓展至其他大规模SPD电路线性求解。
5. 并行性能瓶颈不在本地子域消元，而在顶层稠密矩阵，优化重点应放在分层压缩全局矩阵规模。
