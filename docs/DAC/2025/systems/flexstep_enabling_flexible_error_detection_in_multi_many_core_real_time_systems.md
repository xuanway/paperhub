## 研究概要
本文提出软硬件协同FlexStep多众核实时容错框架，突破LockStep/HMR核绑定、同步校验局限。新增寄存器检查点等微架构单元，配套定制ISA与分区EDF调度，支持异步、可抢占、按需选择性校验。FPGA实测性能减速仅1.07%，面积/功耗开销分别为2.21%、2.89%，任务可调度性大幅优于传统方案。

## 背景和动机
1. 航空、车载安全关键系统需硬件故障检测，传统LockStep强制双核绑定同步执行，所有任务统一最高冗余等级，资源严重冗余、易引发截止期丢失。
2. 改进HMR仍存在强核绑定约束，校验线程不可被高优任务抢占，动态差异化可靠性需求无法适配。
3. 现有软硬件容错方案要么硬件面积功耗开销巨大，要么软件冗余指令带来数十倍性能衰减。
4. 缺少全栈协同方案，无法在微架构、指令集、实时调度三层联动，实现动态切换主/校验核、异步后台校验。
5. 多混杂关键度实时任务共存场景，缺乏理论调度模型支撑可调度性分析。

## 相关工作
1. LockStep系列双核/三核锁步：严格周期同步、核永久绑定，资源利用率极低，混合任务场景调度性能差。
2. HMR混合模块化冗余：支持运行时重配置，但校验线程不可抢占，仍无法动态按需开启校验。
3. 软件容错Nzd等：依靠编译器插入冗余指令，执行减速超50%，部分负载无法编译运行。
4. Paramedic异构并行校验：依赖异构核心，无统一同构SoC适配方案，缺少实时调度协同设计。
5. 传统实时调度算法：未将异步冗余校验计算纳入任务密度建模，无法量化校验带来的执行开销。

## 本文解决方案
### 1 轻量化RISC-V微架构扩展
基于Rocket核新增三大硬件单元：RCP寄存器检查点单元分段捕获架构状态；MAL内存访问日志记录访存轨迹；DBC缓冲互联单元构建可配置多对多核通道，实现异步回放校验，任意核可动态切换主/校验角色。
### 2 专用容错ISA指令集
划分全局、主核、校验三类指令，支持核心角色配置、检查点录制/加载、校验结果上报，OS上下文切换时自动启停冗余校验，上层应用无需修改。
### 3 操作系统内核适配
改造上下文切换逻辑，设计专用校验线程；切换时通过ISA指令动态解绑/绑定校验核心，支持高优任务抢占正在执行的校验流程。
### 4 分区EDF异步调度算法
区分普通/双重/三重校验任务，引入虚拟截止期拆分原始计算与冗余校验负载；按任务密度分核分配，给出可调度判定条件，最大化多核资源复用。
### 5 分层全栈协同机制
硬件提供分段异步回放基础，ISA屏蔽底层微架构细节，OS调度动态分配校验算力，三层联动实现按需、可抢占、多模式冗余切换。

## 实验分析
1. 实验平台：Chipyard+FireSim仿真，AMD Alveo U280 FPGA，TSMC28nm工艺，测试SPECint、Parsec标准负载与随机实时任务集。
2. 性能开销：FlexStep平均执行减速仅1.07%，软件容错Nzd减速超57%；三核校验模式减速小幅升至1.77%。
3. 硬件成本：4核SoC面积开销2.21%、功耗增加2.89%，多核心扩展时面积功耗线性增长，具备良好可扩展性。
4. 故障检测：绝大多数故障检测延迟集中20μs以内，上限不超50μs，满足硬实时安全要求。
5. 调度性能：相比LockStep、HMR，不同任务利用率、混合关键度场景下可调度任务占比显著提升，高负载优势更突出。

## 研究启发
1. 安全实时容错不能仅依赖硬件锁步或软件冗余，微架构-ISA-OS三层软硬件协同可兼顾低开销与高调度性。
2. 解除主核与校验核永久绑定、采用分段异步回放校验，是解决混合关键任务资源浪费的核心思路。
3. 校验计算可作为后台异步负载，通过虚拟截止期调度建模，能充分利用空闲算力且不抢占关键任务。
4. 同构核增加轻量化容错单元远比重构专用容错处理器成本更低，线性扩展适配大规模众核场景。
5. 差异化冗余需求（双/三重校验）可通过可配置片上互联通道统一支撑，一套硬件适配多安全等级业务。
