## 研究概要
本文提出软硬件协同MHDiff扩散模型加速器，提出焦点像素感知量化算法，单步仅首层读取前序特征大幅削减访存；设计打包模块统一混合精度，配套专用PE阵列。28nm流片，相较Cambricon-D、A100、CPU分别提速3.1×、6.2×、38.4×，图像精度损失不足1%，内存流量降低8.1倍。

## 背景和动机
1. 扩散模型多步迭代去噪，传统差分加速器每层读写历史特征，DRAM访存开销极大，带宽成为瓶颈。
2. 高低精度特征分布无规律，分离PE计算频繁同步等待，硬件利用率不足50%，算力闲置严重。
3. 图像生成质量高度依赖变化剧烈的焦点像素，普通全局量化统一位宽，造成精度损失或算力浪费。
4. 同一时间步不同卷积层焦点区域高度重合，现有方案每层重新计算像素差异，存在重复计算冗余。
5. 主流差分加速方案每层都读写前一时间步特征，多层模型下访存放大数倍，推理时延显著拉长。

## 相关工作
1. Cambric-D/HCDiff差分加速器：利用时序数据差值量化，每层均读写历史特征，内存压力巨大；高低精度分开计算，PE利用率低。
2. Q-Diffusion量化方案：仅全局8比特后量化，未区分像素重要性，无法针对性压缩冗余外围像素。
3. DPM-Solver++：算法层面减少采样步数，无硬件协同优化，无法解决访存与硬件利用率问题。
4. 通用CNN量化加速器：面向静态单前向网络，不适配扩散多步迭代、时序依赖的特殊数据流。
5. 通用混合精度PE架构：无像素打包机制，高低精度并行存在大量同步阻塞，推理效率受限。

## 本文解决方案
### 1 焦点像素感知量化算法
单时间步首层通过L1距离判别焦点/外围像素生成掩码；利用卷积特性微调掩码适配所有层；焦点用INT8、低变化外围用INT4量化，兼顾画质与压缩率。
### 2 单次掩码预测微调机制
仅时间步第一层读取前序特征生成掩码，后续层通过卷积修正掩码，省去多层重复访存，DRAM流量大幅下降。
### 3 贪心混合精度打包模块
统计特征内INT8分布，贪心重组4bit碎片合并为完整8bit单元，规避双8bit冲突；生成查找表记录原始像素位置，消除同步等待。
### 4 适配打包数据专用PE单元
内置多路选择器，通过2bit标识区分打包格式，拆分高低4bit并行乘加，支持统一8bit数据流连续运算。
### 5 完整MHDiff硬件流水线
掩码计算单元+打包模块+32×32 PE阵列+多片上缓存，支持Stable/Latent/Guided三类扩散端到端推理。

## 实验分析
1. 实验环境：28nm工艺Verilog综合，500MHz；测试多款扩散模型，对比Xeon CPU、A100、Cambricon-D。
2. 画质指标：量化后图像精度平均下降不足1%，约83%特征压缩为4bit，计算量大幅降低。
3. 性能加速：相对Cambricon-D提速3.1倍、A100提速6.2倍、CPU提速38.4倍；移除打包模块性能下降1.6倍。
4. 访存与能效：内存流量相较基线降低8.1倍，PE空闲时间接近0；能效分别为CPU45.2×、GPU8.3×、Cambricon-D4.4×。
5. 消融与调优：阈值Bias取0.6平衡速度与画质；计算、访存可高度重叠，串行阻塞问题基本消除。

## 研究启发
1. 扩散模型优化不能仅依赖时序差分，像素层级重要性差异是关键压缩抓手，差异化量化可无损压缩大量外围特征。
2. 同时间步多层焦点区域具备强一致性，一次掩码生成多层复用，可从根源削减重复DRAM读写。
3. 混合精度带来的硬件同步瓶颈可通过打包重组数据流解决，统一位宽能显著提升PE阵列利用率。
4. 扩散迭代数据流特殊，通用DNN加速器架构适配性差，需设计掩码、打包专用硬件模块。
5. 访存延迟是扩散推理首要瓶颈，优先减少片外数据交互，再提升计算并行度，收益提升更显著。
