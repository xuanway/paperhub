## 研究概要
本文提出DenSparSA均衡脉动阵列，原生支持单边/双边非稀疏矩阵乘，稀疏管理硬件可门控隔离。设计向量压缩、置换、过滤三类数据流，搭配带缓冲PE单元。45nm流片验证，稀疏场景提速1.9~22倍；稠密模式面积开销15%(BF16)/12%(FP32)，稠密算力效率远超同类稀疏加速器。

## 背景和动机
1. 传统TPU类脉动阵列稠密矩阵乘高效，但无法跳过零元素，处理稀疏DNN、图计算算力浪费严重。
2. 现有稀疏加速器为稀疏大幅修改阵列，稠密任务下面积、功耗开销极高，通用混合负载场景性价比差。
3. 单边稀疏（Transformer权重）、双边稀疏（CNN权重+激活）缺乏统一硬件支持，多数方案仅适配单一稀疏类型。
4. 压缩向量元素索引错位，普通PE无法匹配对应数值，易产生计算错误；压缩带来的阵列停顿会抵消稀疏提速收益。
5. 现有稀疏硬件附加逻辑无法断电，稠密推理时持续产生无效动态功耗，“稀疏税”过高。

## 相关工作
1. 基线TPU脉动阵列：稠密性能最优，无稀疏跳过机制，稀疏计算效率极低。
2. STPU/Mentha：依靠离线数据打包适配稀疏，仅支持有限稀疏模式，泛化性弱。
3. S2 Engine：仅面向CNN双边稀疏，不兼容Transformer单边稀疏场景。
4. SIG/DSSA：重度改造阵列适配稀疏，稠密任务面积/功耗损耗巨大。
5. Trapezoid：稀疏加速倍率高，但稠密负载硬件效率大幅下滑，混合任务平衡差。

## 本文解决方案
### 1 三类稀疏专用数据流
双边稀疏向量压缩：剔除零元素附带索引掩码；单边稀疏向量置换对半交换向量平衡长度；权重已知场景向量合并过滤，进一步缩短输入序列。
### 2 带缓冲可门控PE单元
每个PE集成深度6索引FIFO，通过掩码匹配错位元素；缓冲、比较逻辑独立时钟域，稠密模式时钟门控切断功耗，停顿率低至0.0861%。
### 3 对角PE结果交换机制
非对角PE增加多路选择器，置换计算后半周期交换对称PE累加结果，保证向量置换后内积计算正确。
### 4 输入层数据重排模块
集成掩码合并、路由多路选择器，在线完成向量过滤与置换分发，阵列按4向量粒度分区平衡开销与加速比。
### 5 低侵入式阵列改造
仅在PE增加小型缓冲与控制逻辑，缓存、MAC主体复用传统脉动阵列，基础架构改动极小。

## 实验分析
1. 实现环境：NanGate 45nm工艺，128×128阵列，支持BF16/FP3，400MHz综合仿真。
2. 稀疏性能：单边稀疏提速1.9~5.5倍，双边稀疏2.6~17.5倍，极端稀疏最高达22倍。
3. 硬件开销：稠密模式BF16面积+15%、FP32+12%；稀疏模式功耗提升明显，稠密门控后增幅仅5%~12%。
4. 横向对比：稀疏算力效率与主流方案0.82~1.32倍持平；稠密场景面积/功耗效率1.17~2.28倍领先所有稀疏加速器。
5. 消融验证：缓冲FIFO深度6为最优平衡点；向量置换、过滤均是单边稀疏提速核心模块。

## 研究启发
1. 稀疏加速器不能牺牲稠密性能，采用可门控解耦稀疏逻辑是平衡混合负载的核心设计思路。
2. 单边稀疏不能仅压缩单侧向量，向量置换均衡两路输入长度才能有效缩短阵列流水周期。
3. 小型FIFO缓冲即可解决压缩索引错位问题，无需重构整条脉动数据流，改造代价极低。
4. 面向CNN+Transformer混合推理的通用阵列，必须同时兼容单边、双边两类稀疏模式。
5. 稀疏硬件附加电路独立时钟域设计，可大幅降低稠密推理的无效动态功耗，缓解稀疏税问题。
