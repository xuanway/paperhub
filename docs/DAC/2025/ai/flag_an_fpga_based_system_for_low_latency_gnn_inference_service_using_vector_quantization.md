## 研究概要
本文提出基于FPGA的FLAG低延迟GNN推理服务系统，针对图服务预处理开销、邻域爆炸两大瓶颈。离线对背景节点预计算+融合LSH的向量量化压缩，在线设计轻量化聚合算法，配套编码-计算流水FPGA架构。GCN/GraphSAGE/GAT三类模型相较GPU基线平均提速154×、176×、333×，精度损失控制在0.5%以内。

## 背景和动机
1. 工业大图实时GNN推理分为数据准备、模型计算两步，数据检索与传输占总延迟99%，GPU批量推理方案无法适配在线请求。
2. GNN多层聚合产生邻域爆炸，感受野指数扩张，访存与计算量爆炸，常规邻域采样会丢失精度。
3. 工业图动态更新，仅少量新增目标节点，绝大多数静态背景节点可复用，但现有方案未区分两类节点统一重计算。
4. 图浓缩类压缩会破坏原图动态更新结构，无法支持实时增量推理；传统向量量化仅用于训练，不适配在线服务。
5. 现有GNN加速器FlowGNN仅优化计算单元，未解决前端大图数据预处理瓶颈，端到端加速幅度极低。

## 相关工作
1. GPU GNN推理框架（DGL）：全图提取计算子图，预处理开销巨大，在线服务延迟极高。
2. FlowGNN等专用GNN加速器：仅优化聚合/组合计算流水线，未解决图数据库数据读取瓶颈。
3. 图浓缩GraphSkeleton：压缩全局图结构，动态新增节点无法增量更新，不适合实时业务。
4. VQ-GNN向量量化训练方案：面向模型训练，未设计离线预压缩、在线增量解码推理链路。
5. 邻域采样类GNN优化：以精度损失换取计算量缩减，无法从根源消除邻域指数扩张问题。

## 本文解决方案
### 1 离线预计算+LSH向量量化压缩
区分静态背景节点与动态目标节点；离线预计算背景节点各层隐特征，基于列均值阈值做LSH分桶，分块K-means向量量化存储码本与索引，大幅压缩存储体积。
### 2 轻量化双层聚合算法
拆分目标聚合、背景更新两类运算；复用预压缩背景隐特征，无需逐层遍历多跳邻域，消除邻域爆炸；仅对与目标相连的少量背景节点增量更新。
### 3 FPGA双引擎流水线架构
分为计算引擎与编码引擎：脉动阵列完成特征组合，SIMD阵列实现聚合；设计并行流水隐藏新增节点编码延迟，内置解码器快速读取码本特征。
### 4 阈值驱动节点调度
利用组合层输出二元哈希码对批次节点重排序，提升片上缓存时序局部性，减少重复码本读取开销。
### 5 动态增量更新机制
新增/更新节点仅局部重编码，无需全图重新量化，适配电商、金融动态图实时推理场景。

## 实验分析
1. 实验平台：Xilinx U55c FPGA；基线4×RTX3090 DGL系统、SOTA FlowGNN；测试Arxiv/Reddit等5张大图，GCN/GraphSAGE/GAT三类2~3层模型。
2. 压缩与精度：向量量化压缩倍率8.4~195.8倍，所有数据集分类精度下降≤0.5%。
3. 端到端加速：相较GPU基线三类模型平均提速154×、176×、333×，FlowG仅最高提速1.25倍。
4. 纯计算延迟：FLAG计算部分最高较GPU基线提速468倍，在高平均度Reddit图优势显著。
5. 批次消融：批次越大加速比越高，邻域爆炸带来的预处理开销占比随批次上升，FLAG收益更突出。

## 研究启发
1. 实时GNN推理瓶颈不在计算单元，而在大图数据读取与多跳邻域遍历，系统级软硬件协同优化远优于单纯加速器设计。
2. 工业动态图存在大量静态背景节点，离线预计算+量化压缩是低成本削减在线开销的核心思路。
3. 向量量化结合局部敏感哈希可平衡压缩率与增量更新成本，优于破坏图结构的全局图浓缩方案。
4. GNN硬件必须配套编码/解码专用通路，通过流水线掩盖量化编码带来的额外延迟。
5. 分层拆分聚合运算、区分静态/动态节点，可从算法层面根除邻域爆炸指数复杂度问题。
