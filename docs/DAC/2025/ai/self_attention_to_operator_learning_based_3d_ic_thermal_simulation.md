## 研究概要
本文提出SAU-FNO算子学习框架用于3D IC热仿真，融合FNO、U-Net与自注意力机制，弥补传统FNO高频信息丢失缺陷；引入高低保真迁移学习降低高精度数据集依赖。在三类堆叠3D芯片验证，相较传统有限元工具提速842倍，热预测MSE相比主流算子模型降低50%以上。

## 背景和动机
1. 3D集成芯片功率密度更高，热点问题突出，传统FEM/FDM热求解精度高但网格迭代计算极慢，无法支撑布局迭代优化。
2. 基础FNO仅依靠傅里叶全局建模，难以捕捉局部热点高频温度特征，预测误差大。
3. CNN、PINN类热模型不具备网格不变性，更换芯片尺寸/网格需重新训练，泛化性差。
4. 高精度3D热仿真样本生成耗时昂贵，大规模高保真数据集获取成本极高，制约模型训练效果。
5. 现有U-FNO仅提升局部卷积能力，未建模芯片层间长距离热传导依赖，全局温度预测偏差明显。

## 相关工作
1. 传统数值热工具(COMSOL/MTA)：有限元求解稳态热传导方程，精度高但单例仿真数百秒，迭代设计不可用。
2. CNN类热预测模型：纯数据驱动，无算子网格不变性，跨芯片泛化弱，缺少物理约束。
3. PINN/DeepOHeat：嵌入热传导物理方程，但几何固定，换芯片必须重训，训练周期长。
4. 标准FNO：傅里叶算子具备网格不变，但丢失局部高频热点细节，峰值温度误差大。
5. U-FNO：叠加U-Net补充局部特征，未引入注意力建模长程层间热耦合，全局相关性建模不足。

## 本文解决方案
### 1 SAU-FNO混合算子主干
基础Fourier层嵌入U-Net跳跃连接构建U-FNO模块，利用卷积捕获局部高频温度、傅里叶变换建模全局热传导，保留网格不变特性。
### 2 后置轻量化自注意力模块
网络末端增加空间+通道双注意力块，通过1×卷积生成QKV捕捉3D芯片跨层长距离热依赖，不破坏网格不变性，仅后置部署控制计算开销。
### 3 高低保真迁移学习训练流水线
先用大量低分辨率低成本样本预训练全局传热规律；再以小批量高精度热数据微调，大幅减少高保真仿真样本需求。
### 4 稳态热传导适配损失函数
采用L2损失约束全域温度场，重点优化结温(热点)误差，匹配EDA热仿真核心评价指标。
### 5 多尺寸3D芯片适配架构
针对单核/四核/八核三层堆叠芯片可动态调整通道宽度，适配不同网格分辨率输入，推理无需重训。

## 实验分析
1. 实验环境：三类face-to-back堆叠3D芯片，MTA生成5000组功率-温度配对数据，对比FNO/U-FNO/DeepOHeat与商用FEM工具。
2. 精度指标：SAU-FNO在40/64网格下RMSE全面最优，相较标准FNO下降超50%，芯片热点结温误差控制在0.25K以内。
3. 加速性能：单次预测仅0.27s，对比MTA提速842倍、对比Hotspot提速365倍，精度基本持平COMSOL。
4. 迁移学习效果：4000低保真+1000高保真微调，精度接近全量高精度训练，总训练时长缩短2.5倍。
5. 消融验证：U-Net提升局部高频精度，自注意力显著降低层间耦合误差，二者协同收益最大。

## 研究启发
1. 纯傅里叶全局建模无法满足芯片局部热点预测，U-Net卷积可有效弥补高频特征丢失。
2. 3D IC多层堆叠存在长程热传导关联，自注意力机制是建模跨层温度依赖低成本方案。
3. 算子学习模型天然具备网格不变性，是EDA多尺寸芯片快速仿真最优路线之一。
4. 高低保真迁移学习可大幅削减高精度仿真样本开销，解决工业数据集稀缺痛点。
5. 后置轻量化注意力相比每层插入，在精度损失极小前提下显著降低推理算力开销。
