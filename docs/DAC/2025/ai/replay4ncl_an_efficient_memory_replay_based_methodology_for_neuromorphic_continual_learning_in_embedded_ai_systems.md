## 研究概要
本文提出Replay4NCL脉冲神经持续学习方法，针对现有SpikingLR时序步长过长、开销大问题，采用短时重放搭配动态神经元阈值与学习率补偿 spike信息损失，搭配最优隐数据插入层策略。SHD增量分类任务验证，旧任务精度90.43%，推理提速4.88倍，内存节省20%、能耗下降36.43%。

## 背景和动机
1. 脉冲持续学习(NCL)依靠隐数据重放缓解灾难性遗忘，但主流SpikingLR依赖长时序步长，压缩解压流程带来巨大时延、能耗开销，不适用于无人机等资源受限嵌入式设备。
2. 直接缩减时序步长会大幅减少脉冲数量，造成信息丢失，旧任务识别精度显著衰减，无法平衡效率与模型性能。
3. 缺少适配短时重放的神经元参数自适应调整方案，固定阈值与学习率难以适配稀疏脉冲输入。
4. 隐重放数据插入网络不同层对精度、内存开销影响差异大，缺乏系统化层选择探索策略。
5. 现有NCL方法未统一权衡精度、时延、存储、能耗四大嵌入式核心指标，难以落地边缘智能终端。

## 相关工作
1. 传统DNN持续学习：依赖密集浮点计算，能耗高，不适合低功耗神经形态硬件。
2. 无监督SNN持续学习(STDP/预测编码)：仅静态数据集验证，未适配动态视觉事件流数据。
3. SpikingLR隐重放基线：长时序重放保证精度，但时延、内存、能耗开销极高，嵌入式部署受限。
4. SNN时序步长优化：仅单模型推理加速，未结合持续学习重放机制，无法解决遗忘问题。
5. 各类SNN持续正则/贝叶斯方法：无隐数据重放机制，对抗灾难性遗忘效果弱于重放类方案。

## 本文解决方案
### 1 时序步长轻量化优化
系统性对比100/60/40/20步精度与时延，选定兼顾性能与效率的短时配置；配套脉冲特征压缩存储机制，降低隐重放数据占用内存。
### 2 动态神经元阈值+自适应学习率补偿
时序步长减少导致脉冲稀疏，动态下调膜电位阈值降低放电门槛；同步缩小持续学习阶段学习率，实现平缓权重更新，弥补信息丢失带来的精度损失。
### 3 最优隐重放数据插入层策略
遍历网络各层插入效果，筛选兼顾新旧任务精度、最小内存开销的插入位置；网络分层冻结，仅插入层及输出层参与持续更新。
### 4 三阶段完整训练流水线
预训练完整基础网络→生成压缩短时隐重放数据并动态调整神经元参数→持续学习阶段混合新旧特征迭代，全程自适应调节阈值与学习率。
### 5 基于替代梯度的SNN训练框架
采用快速sigmoid替代梯度近似阶跃激活，适配短时稀疏脉冲下时序反向传播，保障持续学习收敛性。

## 实验分析
1. 实验环境：4层LIF脉冲网络，SHD增量分类数据集，RTX 4090Ti仿真，对比SpikingLR基线，评测精度、时延、隐内存、能耗。
2. 精度表现：旧任务Top-1达90.43%优于基线86.22%，新任务收敛速度更快，长周期训练曲线更平稳。
3. 时延提升：相较SpikingLR最高提速4.88倍，时序步长缩减是核心加速来源。
4. 存储与能耗：隐重放内存节省20%，整体推理能耗降低36.43%，深层插入方案内存优化更明显。
5. 消融验证：动态阈值与学习率二者缺一不可；插入层选择直接决定内存开销与任务精度上限。

## 研究启发
1. 脉冲持续学习无需依靠长时序重放，短时脉冲搭配自适应神经元参数可兼顾效率与抗遗忘能力。
2. 膜电位阈值与学习率协同调整是弥补稀疏脉冲信息缺失的低成本手段，无需改动网络主体结构。
3. 隐重放数据插入层存在最优解，深层网络可大幅减少存储占用，平衡精度与硬件资源。
4. 面向嵌入式神经形态系统的NCL算法，必须同步考量时序、存储、能耗多维度约束，不能只追求识别精度。
5. 时序步长轻量化与隐数据重放机制可融合，为无人机、移动机器人等低功耗边缘设备提供可行持续学习方案。
