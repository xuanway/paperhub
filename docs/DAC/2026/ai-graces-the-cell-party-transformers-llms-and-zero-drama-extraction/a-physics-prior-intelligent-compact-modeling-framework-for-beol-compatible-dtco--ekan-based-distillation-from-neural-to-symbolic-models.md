## 中文标题

面向 BEOL 兼容 DTCO 的物理先验智能紧凑建模框架：基于 EKAN 的从神经模型到符号模型的蒸馏

## 英文摘要

Compact modeling for design–technology co-optimization (DTCO) is increasingly strained by device complexity, layout dependence, slow process bring-up, and the need to sweep large process spaces. Neural compact models achieve high accuracy but are hard to interpret and cumbersome to deploy in standard SPICE flows. To address these challenges and better bridge data-driven and physics-based modeling, we propose a physics-prior neural-to-symbolic compact modeling framework for DTCO based on an Efficient Kolmogorov-Arnold Network (EKAN). The framework learns 𝐼d(𝑉g, 𝑉d, 𝑡ox, 𝑇) from experimentally calibrated oxide-semiconductor field-effect transistors (OS-FETs) TCAD dataset and then distills the EKAN teacher into a SPICE-ready symbolic current expression via KAN-derived 1D atoms, physics-aware feature design, and weighted sparse regression with smoothness-aware refinement. The resulting symbolic model uses only 116 parameters (vs. 6.4 × 102–2.6 × 103 for neural/KAN baselines) and achieves roughly 300× faster offline model build time than an MLP baseline, while maintaining comparable accuracy. It is fully interpretable, directly implementable in Verilog-A, and readily integrable into DTCO-oriented circuit simulation flows.

## 中文摘要

面向设计-工艺协同优化（DTCO）的紧凑建模正日益受到器件复杂性、版图依赖性、工艺爬坡缓慢以及需要扫描大范围工艺空间等因素的制约。神经紧凑模型精度高，但难以解释，且难以在标准 SPICE 流程中部署。为应对这些挑战并更好地衔接数据驱动建模与基于物理的建模，我们提出一种基于高效 Kolmogorov-Arnold 网络（EKAN）的物理先验、由神经到符号的 DTCO 紧凑建模框架。该框架从经实验校准的氧化物半导体场效应晶体管（OS-FET）TCAD 数据集中学习 𝐼d(𝑉g, 𝑉d, 𝑡ox, 𝑇)，随后通过 KAN 导出的一维原子、物理感知的特征设计以及带有平滑性感知精修的加权稀疏回归，将 EKAN 教师模型蒸馏为可直接用于 SPICE 的符号电流表达式。所得符号模型仅使用 116 个参数（相比神经/KAN 基线的 6.4 × 10²–2.6 × 10³），离线模型构建时间比 MLP 基线快约 300 倍，同时保持相当的精度。它完全可解释，可直接用 Verilog-A 实现，并易于集成到面向 DTCO 的电路仿真流程中。
