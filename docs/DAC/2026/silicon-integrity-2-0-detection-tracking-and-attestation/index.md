## Session Description

Ensuring trust in modern silicon requires defending against increasingly sophisticated threats spanning design, architecture, and manufacturing. This session presents advances in hardware Trojan detection, secret tracking, side-channel analysis, undocumented instruction discovery, SRAM aging leakage, ReRAM vulnerabilities, IP protection, and wafer-level tool-chain attestation. Together, these works expose emerging attack surfaces while introducing systematic techniques for detection, verification, and protection across the hardware lifecycle. The session highlights the evolving challenges of building and maintaining trust in silicon from design through deployment.
