Module-Level Placement Using Force-Based Deformation for Efficient Early Design Estimation
Authors：
[Mengen Chen](https://63dac.conference-program.com/?post_type=page&p=15&uid=8684441351985017422)，[Xu He](https://63dac.conference-program.com/?post_type=page&p=15&uid=30892403380736762431)，[Tong Shen](https://63dac.conference-program.com/?post_type=page&p=15&uid=87728949919871278111)，[Yao Wang](https://63dac.conference-program.com/?post_type=page&p=15&uid=63063782924781211831)

## 中文标题

面向高效早期设计估算的力驱动形变模块级布局

## 英文摘要

In modern very large-scale design, cell-level placement is prohibitively slow and memory-intensive, hindering rapid design-space exploration for integrated circuits. Cell-level placement consistently shows that cells within the same functional module tend to group together, making module-level placement a practical abstraction for fast yet accurate design estimation. To this end, we introduce a module-level placement framework with a force-directed soft-module deformation scheme, where functional modules are modeled as deformable entities that adapt aspect ratios under area preservation. This reduces the size of the problem by several orders of magnitude, while retaining high fidelity to cell-level placement. On industrial-scale benchmarks, our approach achieves a 56× average speedup over conventional placers, incurs only about 3% inter-module HPWL error, and recovers 93% of the top-10% longest nets. These results establish a practical and scalable solution for early-stage placement estimation.

## 中文摘要

在现代超大规模设计中，单元级布局速度极慢且内存开销巨大，阻碍了集成电路设计空间的快速探索。单元级布局一致地表明，同一功能模块内的单元倾向于聚集在一起，这使得模块级布局成为一种实用抽象，可在保持较高精度的同时实现快速设计估算。为此，我们提出一种模块级布局框架，采用力导向的软模块形变方案，将功能模块建模为可形变实体，并在保持面积不变的前提下调整其宽高比。这将问题规模降低数个数量级，同时保持对单元级布局的高保真度。在工业级基准上，我们的方法相比传统布局器实现平均 56 倍加速，模块间 HPWL 误差仅约 3%，并恢复了前 10%最长连线中的 93%。这些结果为早期布局估算建立了一种实用且可扩展的解决方案。
