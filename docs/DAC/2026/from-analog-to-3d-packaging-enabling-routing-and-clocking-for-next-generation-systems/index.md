# DAC 2026: From Analog to 3D Packaging Enabling Routing and Clocking for Next Generation Systems

**论文数量：** 10 篇

[Amin Farshidi](https://63dac.conference-program.com/?post_type=page&p=15&uid=034843)

[Yaguang Li](https://63dac.conference-program.com/?post_type=page&p=15&uid=464843)

## Session Description

This session addresses routing, clocking, and related challenges in various advanced technological settings. It begins with a new analytic partitioning algorithm for parallel routing, with applications across various routing scenarios, followed by an approach for rail–signal co-design on modern PCBs. A highlight is a new approach to differentiable clock tree synthesis. The session then covers emerging technologies such as glass-interposer-based 5.5D ICs and Flip-FET design with dual-sided routing. Progress in more traditional routing is presented through a new versatile detailed maze routing method and 3D-aware track assignment. For analog design, a new self-biasing technique is proposed for the placement and routing of analog standard cells. Finally, we will see a new GPU acceleration method for large-scale pattern matching and a controllable DRC violation case generator.
