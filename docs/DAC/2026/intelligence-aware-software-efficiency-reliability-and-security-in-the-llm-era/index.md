## Session Description

This session showcases cutting-edge embedded software techniques designed to maximize performance, efficiency, and robustness in modern computing systems. The papers explore dynamic runtime and scheduling strategies for heterogeneous architectures, smarter resource orchestration for Large Language Models (LLMs) and Vision-Language-Action (VLA) models, and advanced methodologies that strengthen the verifiability and security of real-world deployments. Together, these contributions bridge the gap between high-level AI algorithms and efficient, secure hardware execution.
