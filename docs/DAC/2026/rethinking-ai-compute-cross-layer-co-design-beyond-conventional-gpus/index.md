# DAC 2026: Rethinking AI Compute Cross Layer Co Design Beyond Conventional GPUs

**论文数量：** 9 篇

## Session Description

As AI workloads expand beyond conventional GPU-centric execution, rethinking compute, data movement, and system robustness across layers becomes essential. This session presents nine works that explore cross-layer co-design spanning hardware, architecture, compiler, and algorithm levels. Topics include adaptive communication compression for distributed GNNs, optical neural networks with robustness-aware mapping, chiplet-based accelerator exploration, and compiler-driven data movement reduction for PIM architectures. Novel dataflow paradigms, heterogeneous fine-tuning strategies, distribution-aware sparsity, and multi-instance GPU inference further highlight how decoupling computation, data, and deployment constraints enables efficient and resilient AI systems across emerging platforms and challenging environments.
