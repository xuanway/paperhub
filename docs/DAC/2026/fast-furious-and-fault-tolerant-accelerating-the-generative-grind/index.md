## Session Description

This session highlights cutting-edge techniques for accelerating modern AI workloads through architectural innovation, sparsity, and model-aware optimization. The papers explore efficient implementations spanning stochastic computing, sparse and quantized inference, diffusion and large language models, as well as GPU-based sparse linear algebra. Together, they demonstrate how hardware–algorithm co-design can unlock substantial performance and efficiency gains for emerging AI applications from edge devices to large-scale systems.
