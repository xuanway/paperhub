## Session Description

This session explores embedded and cross-layer security across hardware, architecture, systems, and applications. The papers span Trusted Execution Environments (TEE), microcontrollers, automotive networks, and modern CPUs, addressing both defensive mechanisms—such as verifiable TEE availability, memory safety, and timing mitigation—and cross-layer attacks, including side-channel analysis and adversarial AI. The session also highlights emerging challenges and opportunities in specialized acceleration, with multiple works on zero-knowledge proof, fully homomorphic encryption, and AI ASICs. Together, these papers demonstrate how security must be co-designed across layers to meet the demands of next-generation embedded and specialized computing platforms.
