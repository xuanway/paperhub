## Session Description

This session brings together cutting-edge advances in memory-centric computing for AI, spanning digital and analog compute-in-memory (CIM), CAM-based accelerators, and DRAM/NAND-enabled computation. The papers highlight cross-layer innovation, from device-aware modeling and design technology co-optimization (DTCO) all the way to hardware-algorithm co-design, while addressing critical challenges in reliability and security for edge intelligence.
