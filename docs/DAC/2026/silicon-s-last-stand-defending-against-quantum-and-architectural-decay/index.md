# DAC 2026: Silicon's Last Stand Defending Against Quantum and Architectural Decay

**论文数量：** 10 篇

## Session Chairs

[Ruiyang Qin](https://63dac.conference-program.com/?post_type=page&p=15&uid=734843)

## Session Description

Description: As computing platforms evolve toward open ISAs, confidential computing, post-quantum cryptography, and hardware-accelerated AI, the hardware trust boundary is being fundamentally redefined. This DAC session presents cutting-edge research that exposes systemic vulnerabilities across modern architectures—ranging from RISC-V CPUs and Intel x86 platforms to performance monitoring units, hardware interrupts, and trusted execution domains. Presentations in this session uncover latent RISC-V CPU design flaws using rich instruction construction and differential analysis, and a remote side-channel analysis of ML-KEM on Intel x86 demonstrates practical leakage in post-quantum key encapsulation mechanisms, raising urgent concerns for next-generation cryptographic deployments. Presentations in this session will also reveal how seemingly benign performance-monitoring-unit (PMU) events can be reverse-engineered, manipulated, and how the security risks driven by hardware interrupts can be mitigated. On the defensive side, different methods, including function-as-a-service, secure acceleration of minimal-interaction MPC, practical acceleration of fully homomorphic encryption, secure compute-in-memory with a PUF-based architecture for robust BNN, and securing hardware security benchmarks, will be presented.
