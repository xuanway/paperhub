# DAC 2026: Move Less Compute More Memory Centric Architectures for AI

## Session Description

This session brings together seven papers that advance the state of art in memory-centric computing solutions for modern AI workloads, with a particular emphasis on LLMs and transformer-based models. We need to overcome memory bandwidth, data movement, and energy-efficiency bottlenecks but how? Through hardware-software co-design spanning algorithms, architectures, circuits, and system scheduling. These papers explore complementary innovations including low-bit and nonlinear quantization, sparse attention execution, DRAM-PIM co-execution with minimal interference, systematic CIM dataflow design-space exploration, and more efficient signed-weight mapping and activation conversion for ReRAM/SRAM-based CIM.
