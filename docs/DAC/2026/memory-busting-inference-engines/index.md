## Session Description

This session encompasses nine papers dedicated to innovative architectures and optimizations that turbocharge inference in large language models (LLMs), Mixture-of-Experts (MoE) systems, and Vision Transformers (ViTs). By leveraging processing-in-memory (PIM), near-DRAM processing (NDP), and hybrid compute strategies, these works tackle memory bottlenecks, enhance throughput, and enable efficient edge deployment for memory-intensive tasks like matrix multiplications and autoregressive generation.
