## Session Description

This session explores cutting-edge advances in LLM- and agent-driven RTL generation, verification, debugging, constraint synthesis, and design rule correction. The presented works demonstrate how task-specific fine-tuning, reinforcement learning alignment, multi-agent reasoning, and benchmark-driven evaluation are transforming hardware design automation into a more scalable, reliable, and human-aligned process. Together, these papers chart a path toward intelligent, self-improving EDA workflows that move from prompt to silicon.
