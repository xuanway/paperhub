# DAC 2026: Composable Systems the Catalyst for Memory Acceleration and Design Tools

**论文数量：** 10 篇

## Session Chairs

[Yingjie Li](https://63dac.conference-program.com/?post_type=page&p=15&uid=395843)

[Ji-Hoon Kim](https://63dac.conference-program.com/?post_type=page&p=15&uid=436843)

## Session Description

This session explores the transition from rigid architectures toward composable systems for next-generation computing. The session begins with addressing multi-GPU page migration strategies in a disaggregated memory system, followed by a modular memory simulation tool that traces the memory access path in disaggregated memory systems. The focus then shifts to dynamically reconfigurable accelerators: The third paper demonstrates a composable accelerator architecture that can be reconfigured in real time to support multiple accelerators. Subsequent papers present a reconfigurable disaggregated LLM accelerator, a novel compression technique for GEMM operations in LLMs, and an HBM-based FPGA accelerator for sparse LU factorization used in scientific computing. The session, then, moves to AI training, featuring an on-chip AI training leveraging Tsetlin Automata for feedback-driven learning, and a CPU-FPGA co-design of frequency measurement in data streams. The session concludes with composability in hardware accelerator design tools including 3D FPGA placements and learning-based Task-graph portioning.
