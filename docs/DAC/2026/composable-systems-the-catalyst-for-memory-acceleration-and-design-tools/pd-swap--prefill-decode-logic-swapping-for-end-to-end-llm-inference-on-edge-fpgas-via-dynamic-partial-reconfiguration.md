PD-Swap: Prefill–decode Logic Swapping for End-to-End LLM Inference on Edge FPGAs via Dynamic Partial Reconfiguration

## 中文标题

PD-Swap：通过动态部分重构实现边缘 FPGA 上端到端 LLM 推理的 Prefill–Decode 逻辑交换

## 英文摘要

Aggressively quantized large language models (LLMs), such as BitNet-style 1.58-bit Transformers with ternary weights, make it feasible to deploy generative AI on low-power edge FPGAs. However, as prompts grow to tens of thousands of tokens, edge hardware performance drops sharply with sequence length due to quadratic prefill cost and rapidly increasing KV-cache bandwidth demands, making inference latency of longer context length a first-order system concern. Recent studies on LLMs expose a fundamental prefill–decode asymmetry: prefill is compute-bound and dominated by dense matrix–matrix operations, whereas decoding is memory-bandwidth-bound and dominated by KV-cache traffic. A static accelerator must provision resources and a single dataflow for both regimes, leading to duplicated attention logic, underutilized fabric, and tight LUT/URAM limits that cap model size and usable context. We propose a prefill–decode disaggregated LLM accelerator, PD-Swap, that uses Dynamic Partial Reconfiguration (DPR) to time-multiplex the attention module on edge FPGAs. The core table-lookup ternary matrix multiplication and weight-buffering engines remain static, while the attention subsystem is a reconfigurable partition with two phase-specialized architectures: a compute-heavy, token-parallel prefill engine and a bandwidth-optimized, KV-cache-centric decoding engine. A roofline-inspired model and design space exploration jointly optimize reconfigurable-region size, parallelism under reconfiguration and routability constraints, and reconfiguration latency is hidden by computation latency. PD-Swap achieves up to 27 tokens/s decoding throughput, outperforming prior state-of-the-art works by 1.3×–2.1× (larger gains at longer context lengths), without extra area cost.

## 中文摘要

经过激进量化的大语言模型（LLM），例如具有三值权重的 BitNet 风格 1.58-bit Transformer，使得在低功耗边缘 FPGA 上部署生成式 AI 成为可能。然而，当提示增长到数万个 token 时，由于二次方的 prefill 开销以及快速增长的 KV-cache 带宽需求，边缘硬件的性能随序列长度急剧下降，使得长上下文场景下的推理延迟成为首要的系统性问题。近期关于 LLM 的研究揭示了一种根本性的 prefill–decode 不对称性：prefill 是计算受限的，由稠密矩阵–矩阵运算主导；而解码是内存带宽受限的，由 KV-cache 流量主导。静态加速器必须为这两种模式配置资源并采用单一数据流，从而导致注意力逻辑重复、可编程逻辑资源利用不足，以及严格的 LUT/URAM 限制，进而制约了模型规模和可用上下文长度。我们提出一种 prefill–decode 解耦的 LLM 加速器 PD-Swap，它利用动态部分重构（DPR）在边缘 FPGA 上对注意力模块进行时分复用。核心的表查找三值矩阵乘法与权重缓存引擎保持静态，而注意力子系统是一个可重构分区，包含两种阶段专用架构：计算密集、token 并行的 prefill 引擎，以及带宽优化、以 KV-cache 为中心的解码引擎。一个受 roofline 模型启发的模型与设计空间探索共同优化可重构区域的大小、重构与可布线性约束下的并行度，并且重构延迟被计算延迟所掩盖。PD-Swap 实现了高达 27 tokens/s 的解码吞吐率，相比此前最先进的工作提升 1.3×–2.1×（在更长的上下文长度下收益更大），且没有额外的面积开销。
