COM-BNN: A Configurable Low Power MRAM-Based Computing-in-Memory Accelerator for Binary Convolutional Computations

## 中文标题

COM-BNN：一种面向二值卷积计算的可配置低功耗 MRAM 存内计算加速器

## 英文摘要

In resource-constrained tiny edge devices like MCUs, deploying data/compute-intensive AI like CNNs is challenging. Compute-in-Memory (CIM) and Binary Neural Networks (BNN) offer promising solutions by reducing memory access and simplifying computational load. We propose COM-BNN, a configurable low-power accelerator integrating MRAM-based CIM with serial BNN computation. It introduces a temporal configurable input mechanism and an Integrate-and-Fire (IF) adder for serial MAC operations, plus an Exact Result Inferring (ERI) method for efficient binary convolutional computations. COM-BNN achieves up to 85% energy and 83% power reduction over ADC-based CIM baselines, and enables dynamic latency-power tradeoffs, dropping power to 0.03% in serial mode for edge adaptability.

## 中文摘要

在 MCU 等资源受限的微型边缘设备上，部署 CNN 这类数据/计算密集型 AI 具有挑战性。存内计算（CIM）和二值神经网络（BNN）通过减少内存访问和简化计算负载提供了有前景的解决方案。我们提出了 COM-BNN，一种将基于 MRAM 的 CIM 与串行 BNN 计算相结合的可配置低功耗加速器。它引入了时序可配置输入机制和用于串行 MAC 操作的积分点火（IF）加法器，并提出了一种精确结果推断（ERI）方法，用于高效的二值卷积计算。与基于 ADC 的 CIM 基线相比，COM-BNN 最高实现 85% 的能耗降低和 83% 的功耗降低，并支持动态延迟-功耗权衡，在串行模式下将功耗降至 0.03%，以适应边缘场景。
