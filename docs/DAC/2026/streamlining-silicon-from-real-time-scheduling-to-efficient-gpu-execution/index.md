# DAC 2026: Streamlining Silicon from Real Time Scheduling to Efficient GPU Execution

## Session Description

This session showcases advances that streamline computing from schedules to silicon, spanning optimization, acceleration, and validation. The talks explore Pareto-guided real-time DAG scheduling for latency reduction, followed by Pareto-optimal GEMM mapping on Versal ACAP for energy efficiency. The session then moves down the stack to address efficient FPGA debugging, expandable RISC-V register files for data-intensive workloads, and adaptive sparse tensor code generation for GPUs. To conclude, the session highlights pre-silicon assurance through SystemC fuzzing and transfer-enabled GPU power modeling, offering practical pathways to faster, greener, and safer embedded systems.
