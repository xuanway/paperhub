Schemacoder: Automatic Log Schema Extraction Coder with Residual Q-Tree Boosting
Authors：
[JIAXIN WAN](https://63dac.conference-program.com/?post_type=page&p=15&uid=03075382828834194571)，[Chia-tung Ho](https://63dac.conference-program.com/?post_type=page&p=15&uid=083643)，[RONGJIAN LIANG](https://63dac.conference-program.com/?post_type=page&p=15&uid=314843)，[Cunxi Yu](https://63dac.conference-program.com/?post_type=page&p=15&uid=365743)，[Deming Chen](https://63dac.conference-program.com/?post_type=page&p=15&uid=914343)，[Haoxing Ren](https://63dac.conference-program.com/?post_type=page&p=15&uid=172643)

## 中文标题

SchemaCoder：基于残差 Q-Tree 提升的自动日志模式抽取编码器

## 英文摘要

Log schema extraction, the process of deriving human-readable templates that support clear log understanding from massive volumes of log data, is fundamental for automated debugging and performance analysis across modern Electronic Design Automation (EDA) tool chains. The challenge is amplified in advanced design flows, where logs interweave command scripts, multi-stage progress reports, timing updates, and deeply nested performance tables, rendering manual regular-expression design brittle and non-scalable to evolving tool versions. We introduce SchemaCoder, a fully-automated LLM-driven schema extraction framework that constructs structured log schemas by synthesizing reusable parser code, enabling robust handling of arbitrary unstructured log files and complex EDA tool logs without manual regular-expression design. At its core, SchemaCoder uses a novel Question-Tree (Q-Tree) pattern code generation process to identify pattern codes and utilizes the extracted raw contents to drive a textual residual evolutionary optimizer in the inner loop without relying on a gold labeled dataset. In the outer loop, a residual Q-Tree boosting mechanism identifies additional pattern codes and iteratively refines the parser code. On EDA tool logs from OpenROAD and commercial tools, the structured log schema generated by SchemaCoder enables an average 11.7% improvement in agentic EDA tool log analysis QA tasks (pass@1) over a strong commercial baseline. SchemaCoder also achieves up to 3.3% improvement in the average scores and outperforms state-of-the-art baselines in 9 of 14 applications on LogHub-2.0. The source code and benchmark are available at https://github.com/NVlabs/SchemaCoder.

## 中文摘要

日志模式抽取是从海量日志数据中导出可读模板、以支持清晰日志理解的过程，对于现代电子设计自动化（EDA）工具链中的自动化调试与性能分析至关重要。在先进设计流程中，这一挑战更为突出：日志中交织着命令脚本、多阶段进度报告、时序更新以及深度嵌套的性能表格，使得人工设计正则表达式既脆弱又难以随工具版本演进而扩展。我们提出 SchemaCoder，一个全自动、由 LLM 驱动的模式抽取框架，它通过合成可复用的解析器代码来构建结构化日志模式，从而无需人工设计正则表达式即可稳健处理任意非结构化日志文件与复杂的 EDA 工具日志。SchemaCoder 的核心是一种新颖的问题树（Q-Tree）模式代码生成过程，用于识别模式代码，并利用抽取出的原始内容在内层循环中驱动文本残差演化优化器，而无需依赖黄金标注数据集。在外层循环中，残差 Q-Tree 提升机制识别更多模式代码并迭代精化解析器代码。在来自 OpenROAD 与商业工具的 EDA 工具日志上，SchemaCoder 生成的结构化日志模式使智能体式 EDA 工具日志分析问答任务（pass@1）相比强劲的商业基线平均提升 11.7%。在 LogHub-2.0 上，SchemaCoder 的平均得分最高提升 3.3%，并在 14 个应用中的 9 个上优于当前最优基线。源代码与基准见 https://github.com/NVlabs/SchemaCoder。
