# DAC 2026: Scaling the Bedrock OS Hardware Co Design for High Reliability Storage

**论文数量：** 7 篇

## Session Chairs

[Shuai Zhao](https://63dac.conference-program.com/?post_type=page&p=15&uid=904843)

## Session Description

This session explores the bedrock of the digital era, pushing the physical and architectural limits of modern storage. By harmonizing OS-Hardware co-design through CXL-based tiered memory and optimizing ZNS SSD management, these papers architect a high-reliability, low-latency foundation for hyperscale data centers. Addressing critical challenges such as 3D NAND aging and QLC endurance, this session pioneers a 'Software-Defined Reliability' model. These innovations ensure that our underlying infrastructure remains a resilient, high-speed nervous system capable of sustaining the demands of future cloud and edge computing.
