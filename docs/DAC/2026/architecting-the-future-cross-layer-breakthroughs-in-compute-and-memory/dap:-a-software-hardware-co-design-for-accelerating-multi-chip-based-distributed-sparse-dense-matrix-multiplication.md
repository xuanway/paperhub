## 中文标题

DAP：一种加速基于多芯粒的分布式稀疏—稠密矩阵乘法的软硬件协同设计

## 英文摘要

Sparse-dense matrix multiplication (SpMM) is a core component in many critical applications such as deep learning and scientific computing. Existing SpMM accelerators employ the COO format to compress sparse matrices and rely on high-bandwidth off-chip memory for performance gains. However, four major challenges remain unaddressed: 1) Fixed 2-D partitioning strategies lead to workload imbalance among processing nodes due to irregular distribution of non-zero elements in sparse matrices. 2) Redundant metadata from the COO format results in a communication bottleneck that hinders the scalability of existing SpMM accelerators. 3) To accommodate irregular memory access patterns, the use of multiple data replicas significantly increases the pressure on on-chip storage resources. 4) Handling RAW hazards from floating-point adders in software incurs substantial pre-processing overhead. To address these challenges, we propose DAP, the first 2-D multi-chip-based architecture composed of dedicated accelerators, and SPU, a novel communication-friendly SpMM accelerator. To mitigate load imbalance caused by irregular non-zero distribution, we design a two-level matrix partitioning framework that effectively balances workloads across nodes in a 2-D computing array, achieving an average performance improvement of 1.63×. Furthermore, the SPU adopts CSC over COO format to reduce communication traffic. SPU also minimizes redundant on-chip storage from dense matrix replication, with only a performance penalty of 0.067× due to memory access conflicts. By employing a reservation buffer, the SPU resolves RAW dependencies without time-consuming element-wise pre-processing. Our simulation-based evaluation demonstrates that DAP achieves geometric mean throughputs of 2.69× relative to NVIDIA A100 GPU at 500MHz frequency.

## 中文摘要

稀疏—稠密矩阵乘法（SpMM）是深度学习与科学计算等众多关键应用的核心组成部分。现有 SpMM 加速器采用 COO 格式压缩稀疏矩阵，并依赖高带宽的片外存储器来获取性能增益。然而，仍有四个主要挑战尚未解决：1）固定的二维划分策略会因稀疏矩阵中非零元素分布不规则而导致处理节点间的工作负载不均衡；2）COO 格式产生的冗余元数据造成通信瓶颈，阻碍了现有 SpMM 加速器的可扩展性；3）为适应不规则的访存模式，使用多份数据副本会显著增加片上存储资源的压力；4）在软件中处理浮点加法器的 RAW 冒险会带来可观的预处理开销。为应对这些挑战，我们提出 DAP——首个由专用加速器构成的基于二维多芯粒的架构，以及 SPU——一种新颖的通信友好型 SpMM 加速器。为缓解非零元素分布不规则引起的负载不均衡，我们设计了两级矩阵划分框架，在二维计算阵列的各节点间有效均衡工作负载，平均性能提升 1.63 倍。此外，SPU 采用 CSC 而非 COO 格式以减少通信流量。SPU 还最大限度地减少了稠密矩阵复制带来的冗余片上存储，仅因访存冲突造成 0.067 倍的性能损失。通过使用预留缓冲区，SPU 无需耗时的逐元素预处理即可解决 RAW 依赖。基于仿真的评估表明，在 500 MHz 频率下，DAP 相较于 NVIDIA A100 GPU 实现了 2.69 倍的几何平均吞吐量。
