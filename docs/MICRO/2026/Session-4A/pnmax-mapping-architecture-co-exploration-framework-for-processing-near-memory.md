# PNMAX: Mapping-Architecture Co-Exploration Framework for Processing Near Memory

**中文标题：** PNMAX：面向近存处理的映射与架构协同探索框架

**所属 Session：** [Session 4A](index.md) · [MICRO 2026](../index.md)

**作者：** Chien-Yi Yang, Jiantao Liu, Yue Pan, Tajana Rosing, Minxuan Zhou, Lana Josipović

**来源：** MICRO 2026，pp. 1313–1331；[DOI](https://doi.org/10.1109/MICRO67795.2026.00099)

## 英文摘要

Processing near memory (PNM) mitigates the memory wall bottleneck in bandwidth-bound workloads, but its effectiveness depends on both the architectural design and the way a kernel is mapped onto hardware. However, existing PNM design exploration methods do not consider the complete mapping-architecture co-design space and lack a comprehensive PPA cost model, resulting in suboptimal designs. In this work, we introduce PNMAX, a novel design-space exploration (DSE) framework that effectively co-optimizes PNM mapping and architecture. PNMAX ensures the efficiency, effectiveness, and flexibility of mapping-architecture co-exploration through several key innovations, including: (1) a parameterized graph-based architecture specification capturing comprehensive hardware characteristics of PNM architectures; (2) a hardware-aware mapping formulation that concretely describes the hardware-dependent mapping choices; and (3) a bottom-up cost and constraint modeling framework that derives comprehensive and composable Performance, Power, and Area (PPA) costs. We exploit PNMAX to jointly optimize hardware parameters and software mappings of various existing and future PNM systems. Evaluations across representative AI/ML workloads demonstrate superior mapping quality and hardware efficiency of designs generated by PNMAX. We also exploit PNMAX to co-optimize mapping and architecture under unconventional architectural configurations, revealing several novel insights for pathfinding future PNM systems.

## 中文摘要

近存处理 (PNM) 可以缓解带宽受限工作负载中的内存墙瓶颈，但其有效性取决于架构设计和内核映射到硬件的方式。然而，现有的 PNM 设计探索方法没有考虑完整的映射架构协同设计空间，并且缺乏全面的 PPA 成本模型，导致设计不理想。在这项工作中，我们介绍了 PNMAX，这是一种新颖的设计空间探索 (DSE) 框架，可以有效地共同优化 PNM 映射和架构。 PNMAX 通过多项关键创新确保了映射架构协同探索的效率、有效性和灵活性，包括：（1）基于参数化图的架构规范，捕获 PNM 架构的综合硬件特性； (2) 硬件感知映射公式，具体描述依赖于硬件的映射选择； (3) 一个自下而上的成本和约束建模框架，可得出全面且可组合的性能、功耗和面积 (PPA) 成本。我们利用 PNMAX 来联合优化各种现有和未来 PNM 系统的硬件参数和软件映射。对代表性 AI/ML 工作负载的评估表明 PNMAX 生成的设计具有卓越的映射质量和硬件效率。我们还利用 PNMAX 在非常规架构配置下共同优化映射和架构，揭示了未来 PNM 系统寻路的一些新颖见解。
