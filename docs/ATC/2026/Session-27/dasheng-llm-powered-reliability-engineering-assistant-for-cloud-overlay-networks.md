# Dasheng: LLM-powered Reliability Engineering Assistant for Cloud Overlay Networks

## 英文摘要
Amid mounting incidents of network failures, cloud service providers are placing increasing emphasis on reliability engineering. Leveraging their capabilities in text understanding and reasoning, Large Language Models (LLMs) have been integrated to assist conventional cloud network reliability tools. However, deploying an LLM-powered reliability engineering assistant to cloud overlay networks is significantly challenging due to the scale, complexity, and intricate couplings of cloud overlay network components. In this work, we present Dasheng, an LLM-powered reliability engineering assistant for cloud overlay networks. Dasheng extends the standard assistant paradigm with an iterative, multi-step tool interaction mechanism to fit the characteristics of cloud overlay networks. Dasheng has been deployed on a production cloud for two years. To date, it has been used by 1,450 engineers for approximately 70k invocations. Most Dasheng invocations complete within 3-100 seconds, and reduce case resolution time by up to 97%. In 92% of evaluated cases, Dasheng produces useful outputs that materially assist engineers.

## 中文摘要
随着网络故障事件不断增多，云服务提供商日益重视可靠性工程。借助大语言模型（LLM）在文本理解与推理方面的能力，人们已将 LLM 集成进来辅助传统的云网络可靠性工具。然而，由于云叠加网络的规模、复杂性以及各组件之间的复杂耦合，将 LLM 驱动的可靠性工程助手部署到云叠加网络极具挑战。在本工作中，我们提出 Dasheng，一个面向云叠加网络的 LLM 驱动可靠性工程助手。Dasheng 通过迭代式、多步的工具交互机制扩展了标准助手范式，以适应云叠加网络的特性。Dasheng 已在生产云上部署两年。迄今为止，已有 1,450 名工程师使用它，调用量约 70k 次。大多数 Dasheng 调用在 3–100 秒内完成，并将案例解决时间最多缩短 97%。在 92% 的评估案例中，Dasheng 产生了能够切实帮助工程师的有效输出。
